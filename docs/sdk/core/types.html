sdk.core.types

Typed data models for every structure the OpenRouter API returns.

All classes are plain dataclasses with full type hints. Parsing is complete: every field the endpoints expose is captured into a typed structure, even when the CLI does not currently render it, so the data is available for future use cases (routing, cost estimation, provider vetting, etc.).

Structure mirror of the API:

  • Pricing / DisplayPrice - per-token raw + per-M display pricing
  • ReasoningConfig - reasoning tokens/effort config
  • ModelFeatures - feature flags (reasoning, tooling)
  • ProviderDataPolicy - training/retention privacy policy
  • ProviderInfo - upstream provider identity + policy
  • EndpointCapabilities - endpoint flags (tools, multipart, etc.)
  • ProviderEndpoint - a single upstream host for a model
  • ModelCard - full model object (find + endpoint.model)
  • ModelEntry - flattened row used by list/compare output
  • PerformanceEntry - one row from the TPS rankings endpoint

 58def _to_bool(value) -> bool:
 59    if value is None:
 60        return False

 62        return value

115@dataclass
116class Pricing:
117    """Raw per-token pricing plus the display-price breakdown.
118
119    ``prompt`` / ``completion`` are per-token USD strings from the API;
120    the convenience properties expose USD per 1M tokens as floats.
121    """
122
123    prompt: str = ""
124    completion: str = ""
125    discount: float = 0.0
126    display_pricing: list[DisplayPrice] = field(default_factory=list)
127
128    @property
129    def prompt_per_million(self) -> float:
130        return max(_to_float(self.prompt) * 1_000_000, 0.0)
131
132    @property
133    def completion_per_million(self) -> float:
134        return max(_to_float(self.completion) * 1_000_000, 0.0)
135
136    @property
137    def is_free(self) -> bool:
138        return self.prompt_per_million == 0.0 and self.completion_per_million == 0.0
139
140    @classmethod
141    def from_raw(cls, raw: Any) -> "Pricing":
142        raw = _to_dict(raw)
143        return cls(
144            prompt=_to_str(raw.get("prompt")),
145            completion=_to_str(raw.get("completion")),
146            discount=_to_float(raw.get("discount")),
147            display_pricing=[
148                DisplayPrice.from_raw(d) for d in (raw.get("display_pricing") or []) if isinstance(d, dict)
149            ],
150        )
